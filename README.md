# nitaking/skills

## Install

Install an individual skill (global / user scope):

```sh
apm install -g nitaking/skills/<skill-name>
```

Or add to a project's `apm.yml`:

```yaml
dependencies:
  apm:
    - nitaking/skills/<skill-name>
```

Pin to a tag:

```sh
apm install -g nitaking/skills/<skill-name>#v0.1.0
```
